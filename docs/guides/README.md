# Guides

Comprehensive guides for using with-context-mcp effectively.

## Available Guides

### [Sessions Guide](./sessions.md)

Complete guide to session management, changelog tracking, and todo management.

**Topics Covered:**

- What are sessions and when to use them
- Session lifecycle (start, pause, resume, end)
- Changelog tracking with conventional commit types
- Todo management with priorities and status
- Best practices and complete workflow examples

**Best For:** Developers who want to track their work sessions, maintain changelogs, and manage todos within their development workflow.

---

### [Templates Guide](./templates.md)

Complete guide to the template system for creating consistent documentation.

**Topics Covered:**

- How the template system works
- Available built-in templates
- Creating custom templates
- Variable substitution and auto-fill
- Integration with MCP tools

**Best For:** Teams who want consistent documentation structure and automated note creation.

---

### [Vault Organization Guide](./vault-organization.md)

Intelligent vault organization with automated content analysis and reorganization.

**Topics Covered:**

- Analyzing vault structure and content
- Automatic file categorization
- Organization presets (clean, minimal, docs-as-code, research)
- Safe reorganization with link updates
- Orphan detection and impact assessment

**Best For:** Users with disorganized vaults who want intelligent, automated organization.

---

### [Vault Presets Guide](./vault-presets.md)

Detailed guide to organization presets for different documentation workflows.

**Topics Covered:**

- What are presets and why use them
- All 4 available presets (clean, minimal, docs-as-code, research)
- Preset comparison and selection guide
- Customization with custom rules
- Before/after examples

**Best For:** Users who want battle-tested organization strategies for their specific workflow.

---

### [Auto-Tracking Guide](./auto-tracking.md)

Automatic session management for the OpenCode plugin.

**Topics Covered:**

- Auto-session management features
- Project detection and configuration
- Smart file tracking and suggestions
- Environment variable configuration
- Implementation status and roadmap

**Best For:** OpenCode users who want hands-free session tracking and automatic change detection.

---

## When to Use Each Guide

### I want to track my development work

→ **[Sessions Guide](./sessions.md)** - Learn how to start sessions, track changes, and manage todos

### I want consistent documentation

→ **[Templates Guide](./templates.md)** - Use professional templates for meeting notes, API docs, and more

### My vault is disorganized

→ **[Vault Organization Guide](./vault-organization.md)** - Analyze and reorganize your vault intelligently

### I need a documentation strategy

→ **[Vault Presets Guide](./vault-presets.md)** - Choose a preset that matches your workflow

### I use OpenCode and want automation

→ **[Auto-Tracking Guide](./auto-tracking.md)** - Enable automatic session tracking and file monitoring
